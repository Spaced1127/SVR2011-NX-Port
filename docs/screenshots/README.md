# Screenshots

Game screenshots of the `deko3d` branch running on Switch hardware, added by
the maintainer as documentation. They are not build inputs and not game assets
used by the port.

Drop images in this folder as `*.png`, `*.jpg`, `*.jpeg` or `*.webp`. The
release guard allows images only under `docs/screenshots/`; the repository's
global image ignore has an exception for this folder.

Suggested set:

- `01-menus.png` — the game's main menu
- `02-in-ring.png` — the 1v1 in-ring view
- `03-attack.png` — an attack / impact frame
- `04-entrance.png` — an entrance (optional)

The README and `docs/RELEASE-deko3d.md` link to this folder. Keep the images
at a reasonable size (under 10 MB each) and remove personal overlays, friend
codes or other identifying information before adding them.
