# Screenshots

Game screenshots of the `deko3d` branch running on Switch hardware, added by
the maintainer as documentation. They are not build inputs and not game assets
used by the port.

Drop images in this folder as `*.png`, `*.jpg`, `*.jpeg` or `*.webp`. The
release guard allows images only under `docs/screenshots/`; the repository's
global image ignore has an exception for this folder.

Current set (Switch handheld, deko3d build, 1280x720; the top overlay shows
the overclocked clocks):

- `01-title-screen.jpg` — the title screen / Press START
- `02-match-select.jpg` — KANE VS. HURRICANE match select

The README gallery embeds both; `docs/RELEASE-deko3d.md` links here. Keep the
images at a reasonable size (under 10 MB each) and remove personal overlays,
friend codes or other identifying information before adding them.
